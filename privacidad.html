Funcionamiento de los formularios

Cuando el envío automático esté activado, los formularios de presupuesto y contacto transmitirán los datos que introduzca el visitante al servidor de la web para registrar la solicitud en una base de datos gestionada mediante Supabase y permitir su seguimiento por personal autorizado. Hasta que se active el sistema automático, el formulario abrirá la aplicación de correo del visitante y el envío solo se completará cuando este lo confirme. La información facilitada se utilizará para responder a las consultas y solicitudes de presupuesto.

Finalidad de las consultas

Si decides enviar un mensaje, los datos que incluyas se utilizarán para gestionar tu consulta o petición de presupuesto según la política aplicable del responsable.

Cookies y herramientas externas

Esta web puede utilizar Cloudflare Turnstile para proteger los formularios frente al envío automatizado. Turnstile es un servicio externo que realiza comprobaciones técnicas para distinguir tráfico legítimo de automatizaciones. La política debe revisarse para incorporar toda la información exigible sobre los proveedores empleados, las bases jurídicas del tratamiento, conservación y ejercicio de derechos antes de utilizar el sistema con datos reales.
